## API reference

This package is a Roslyn component: it runs in the compiler and emits code into your project, so it
has no runtime API of its own. The types it generates use
[Moongazing.OrionGuard.Core](xref:Moongazing.OrionGuard.Core) and
[Moongazing.OrionGuard.Attributes](xref:Moongazing.OrionGuard.Attributes) from the core package.
