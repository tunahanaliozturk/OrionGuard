# Security policy

## Supported versions

Security fixes land on the latest released major version of each package in this repository. Older majors
receive a fix only when the issue is critical and the upgrade path is not reasonable; the advisory says so.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a vulnerability.

Report it privately through GitHub:
**[Report a vulnerability](https://github.com/tunahanaliozturk/OrionGuard/security/advisories/new)**
(Security tab, "Report a vulnerability").

Include:

- the package and version, and the target framework;
- what an attacker can do, and under which configuration;
- a minimal reproduction or proof of concept;
- any fix or mitigation you already know of.

## What happens next

- You get an acknowledgement within 7 days.
- The report is confirmed or declined with reasoning. A confirmed issue gets a fix, a patched release on
  nuget.org and a published GitHub security advisory, crediting you unless you ask otherwise.
- Please keep the details private until the advisory is published.
